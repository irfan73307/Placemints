# Placemints — SASTRA Student Placement Preparation Platform

Placemints is a full-stack campus placement preparation portal built specifically for SASTRA University students.

## Features
- **Company Selection Archives**: 246+ company selection round breakdowns, CTC packages, eligibility criteria, and preparation tips.
- **SASTRA Previous Interview Questions (PYQs)**: Frequency ratings, expected interview rounds, time/space complexities, and LeetCode problem links.
- **Saved Companies Library**: Bookmark target recruiters; synced directly across Dashboard, Library, and Profile.
- **Interactive Student Profile**: Live synchronization with LeetCode, GitHub, Codeforces, and LinkedIn platforms.
- **Dark / Light Theme Toggle**: Persistent theme choice across browser restarts.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Lucide Icons, Axios, React Router v6.
- **Backend**: Node.js, Express, Prisma ORM, JWT authentication, bcryptjs, SQLite / PostgreSQL.

## Getting Started

### 1. Frontend Setup
```bash
npm install
npm run dev
```

### 2. Backend Setup
```bash
cd server
npm install
npm run seed
npm start
```
